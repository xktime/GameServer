# Match 拥有在线玩家读取接口

_状态：在线准入与取消部分仍有效；机器人选择部分由 ADR 0003 取代。_

Match 原本在匹配准入、取消和机器人选择中直接读取 Game 的 `UserManager`、`TeamManager` 及可变对象。我们决定由 Match 定义只返回值快照的三方法读取接口，Game 提供生产适配器，测试提供内存适配器；这保留“仅在线玩家参与”的现有语义，同时避免建立一个镜像整个 Game 管理器的大而浅接口。

本阶段只迁移匹配准入、取消和机器人选择，并在启动时显式注册 MatchManager。房间创建、Team 房间状态和消息发送仍作为下一条独立切片，避免一次改动跨越全部匹配生命周期。

生产适配器会立即复制 Match 所需字段，但本决策不宣称已经解决 Game 内部 Player、Team Actor 的并发所有权问题；旧管理器仍返回可变对象的风险留在 Game 内单独收口。
